# Quick Task 260806-k98: Fix PDP Parity Issues vs Production Summary

Closed five PDP parity defects against production: description now renders once with
no derived accordions, all displayable tags render as pills, the review line always
shows ("0 Reviews" at zero), the production availability message follows the selected
variant, and bulk tier totals use multiply-then-round arithmetic (54.48 / 103.23 /
201.87 / 389.98 for an 11.47 base).

## What Changed

**Defect 1 — derived accordions removed.** Deleted `SpecDisclosure`, the derived
Tasting/Ingredients/Packing tables, `getCertificationLabel`, the `ChevronDown`
import, and the dead lib code (`extractProductDescriptionDetails`,
`ProductDescriptionDetails`, `PRODUCT_DESCRIPTION_LABELS`) from
`src/lib/shopify/html-content.ts`. The description still renders once above the buy
panel via the existing `sanitizeShopifyCompactHtml` + `RichText` path.
`plainTextFromHtml` kept (other consumers). `grep -rn extractProductDescriptionDetails src`
returns nothing.

**Defect 2 — availability message.** `ProductForm` renders a `type-caption` line
after the selected-pack price row: `In stock! Usually ships within 24 hours.`
(`text-brand`) or `Sorry! This product is currently out of stock.` (`text-danger`,
same token as the quantity error). No new live region; the quantity `role="status"`
paragraph remains the only one. "Sold Out" button label unchanged.

**Defect 3 — tag cap.** `visibleTags.slice(0, 6)` → `visibleTags.map(...)`; a
product with 8 displayable tags renders 8 pills; `Package_*` tags stay hidden via
`formatTag`.

**Defect 4 — bulk totals.** New `getTierUnitAmount` returns the unrounded discounted
unit amount (or `parseAmount(tier.price)` for explicit tiers); the tier total is
`(unitAmount × minimumQuantity).toFixed(2)`. Per-unit displays and struck-through
base totals unchanged. Regression test pins 54.48 / 103.23 / 201.87 / 389.98.

**Defect 5 — zero reviews.** Star row renders unconditionally; count 0 renders
exactly `0 Reviews` (capital R, no rating prefix); count > 0 keeps
`{rating.toFixed(1)} · {count.toLocaleString()} review|reviews`.
`src/lib/reviews/summary.ts` untouched; JSON-LD `aggregateRating` gate unchanged
(zero-review products emit no aggregateRating — verified by test).
